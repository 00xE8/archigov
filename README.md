# Contributor licence agreements

`signatures.json` records who has agreed to the [Archigov CLA](https://github.com/00xE8/archigov/blob/main/docs/CLA.md): GitHub login and account id, CLA version, date, the pull request and a link to the agreeing comment.

It is written only by the CLA workflow (`.github/workflows/cla.yml` on `main`). This branch is never merged. Correct a record only with a commit that says why. See [CONTRIBUTING.md](https://github.com/00xE8/archigov/blob/main/CONTRIBUTING.md).
